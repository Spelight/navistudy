# Public content boundary

This repository publishes application code and independently authored demo fixtures. It excludes textbook text, textbook page images, course question banks, reference PDFs/Word files, production environment values, internal conversations, server runbooks, user records and database exports.

Sample data is generated by `scripts/demo-data.cjs`. It demonstrates schemas and interactions rather than reproducing a curriculum. Course-specific practice pools are empty. Add only content you are entitled to distribute.

Do not push private Git history into this repository. Export reviewed source into a public checkout, regenerate samples, review the full diff and run public checks before pushing.

Application service endpoints use reserved example domains. README links identify the live product; they are not a backend for public development.
