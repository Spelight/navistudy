# Design System

## Direction

NaviStudy extends the existing dark study-console identity shared by NaviWords and NaviMT. The launcher feels like a quiet subject switchboard: direct, compact, and immediately actionable.

## Launcher

- NaviStudy is the first and strongest signal.
- Two large subject rows carry the actual product choices rather than feature marketing.
- Recent-module continuation appears only after the user has entered a module.
- Blue identifies the shared Navi system; teal distinguishes language study and amber distinguishes Military Theory without splitting the visual family.

## Module Navigation

- Each module keeps three native task destinations and gains one NaviStudy switcher.
- Navigation is rendered per module instead of using the global WeChat tab bar.
- Module data, status colors, and interaction conventions remain unchanged.
