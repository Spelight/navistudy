# DXIR Words 微信小程序

本目录是 `words.dxir.net.cn` 的微信小程序本地开发版。

## 当前范围

- 内置 Book 3、Book 4、Book 5、双学位词汇，共 1147 条。
- 底部导航控制在 3 个：学习、词表、我的；错题本保留为学习页和我的页快捷入口。
- 已接入远端接口：
  - `https://words.dxir.net.cn/userdata.php`
- 当前核心背词路径：教材选择、Unit 筛选、背诵卡、选择题、拼写题、收藏、错题记录与复习、词条状态图、用户名同步。
- 2026-09-07 起按“航概题库”参考页升级为深色学习控制台：学习页显示教材、范围进度、错题、收藏和练习模式；词表页支持 Unit 状态圆点；我的页收纳账号、同步、导入导出、网页版和公告恢复。
- 已启用小程序按需注入：`lazyCodeLoading: requiredComponents`。当前没有自定义组件，因此暂不配置用时注入。

## 使用方式

1. 打开微信开发者工具。
2. 导入项目目录：`D:\事务\服务器\04_英语词汇学习\words-wechat-miniprogram`。
3. AppID 目前为 `touristappid`，正式发布前需要替换为你的小程序 AppID。
4. 小程序后台需要配置 request 合法域名：`https://words.dxir.net.cn`。

## 注意

- `/fayu/` 法语站不在本次小程序范围内。
- 备考中心的所有专项题尚未完整迁移；当前先保留核心背词与错题复习闭环。

## 版本

- 当前应用内版本：`0.2.1`。
- 应用内版本由 `miniprogram/app.js` 的 `globalData.version` 提供，在“我的”页面展示。
- 微信开发者工具上传时填写的版本号由微信平台独立管理；上传测试版时应填写与应用内相同的版本号，二者不会自动同步。
